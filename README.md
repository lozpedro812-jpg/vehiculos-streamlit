🚗 Análisis Interactivo de Vehículos en EE.UU.

Aplicación desarrollada con Streamlit

Este proyecto presenta una aplicación web interactiva construida con Streamlit, diseñada para explorar y analizar anuncios de vehículos usados publicados en Estados Unidos. La herramienta permite filtrar, visualizar y comprender patrones clave del mercado automotriz de forma intuitiva y dinámica.

---

📊 Demo en vivo

👉 https://vehiculos-streamlit.onrender.com/

---

🧠 Objetivo del proyecto

El propósito de esta aplicación es ofrecer una plataforma accesible para:

• Analizar tendencias de precios y características de vehículos usados.
• Explorar distribuciones y relaciones entre variables relevantes.
• Facilitar la toma de decisiones basada en datos para compradores, analistas o entusiastas del mercado automotriz.


---

🛠️ Funcionalidades principales

• Filtros interactivos por marca, modelo, año, precio, estado y más.
• Visualizaciones dinámicas para identificar patrones y comportamientos del mercado.
• Exploración intuitiva incluso para usuarios sin experiencia técnica.
• Procesamiento eficiente de datos para una experiencia fluida.
