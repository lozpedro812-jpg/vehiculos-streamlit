# my_project
Análisis de Anuncios de Vehículos en EE.UU.

Este proyecto es una aplicación interactiva desarrollada con Streamlit que permite explorar y analizar anuncios de vehículos usados publicados en Estados Unidos. A través de una interfaz limpia y dinámica, el usuario puede aplicar filtros personalizados y visualizar patrones clave del mercado automotriz.

🚗 Características principales

• Filtros interactivos para explorar el dataset según marca, modelo, año, precio, estado y otros atributos relevantes.
• Visualizaciones dinámicas que facilitan la comprensión de tendencias, distribuciones y relaciones entre variables.
• Interfaz intuitiva, diseñada para que cualquier usuario —técnico o no técnico— pueda navegar y obtener insights rápidamente.
• Procesamiento eficiente de datos, permitiendo análisis fluidos incluso con grandes volúmenes de información.


🎯 Objetivo del proyecto

Brindar una herramienta accesible para analizar el mercado de vehículos usados en EE.UU., identificando patrones de precios, disponibilidad y características más demandadas. Es ideal tanto para entusiastas del análisis de datos como para profesionales que buscan entender el comportamiento del mercado automotriz.

🛠️ Tecnologías utilizadas

• Python
• Streamlit
• Pandas
• Plotly / Matplotlib / Seaborn (según lo que hayas usado)
• Render para despliegue en la nube
